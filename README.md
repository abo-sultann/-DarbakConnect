# Darbak Connect — دربك اتصال

تطبيق خاص يربط الآيفون بشاشة السيارة عبر شبكة Wi‑Fi المحلية، بدون استضافة خارجية وبدون حسابات سحابية.

## الإصدار 1.0.0

- Android 7.1 / API 25 فما فوق.
- واجهة سيارة أفقية محسّنة لدقة 1024×600 ومتوافقة مع WebView القديم.
- واجهة آيفون RTL بهوية دربك الليلية: كحلي/أسود + أزرق/سماوي.
- خادم محلي على المنفذ `8765`.
- دخول محمي برمز PIN من 4 أرقام، مع إيقاف مؤقت بعد المحاولات الخاطئة المتكررة.
- عرض التطبيقات القابلة للفتح وأيقوناتها وإصداراتها وتشغيلها عن بعد.
- إرسال MP3 والفيديو والصور وAPK من Safari إلى الشاشة مع متابعة التقدم.
- فحص ملف APK قبل اعتماده ومقارنة إصداره بالنسخة المثبتة.
- فتح مثبت Android الرسمي للتحديث؛ لا يستخدم تثبيتًا صامتًا أو Root.
- عرض RAM والتخزين والطاقة وAndroid وIP ووقت التشغيل.
- سجل محلي لآخر العمليات.
- تشغيل خدمة Darbak Connect مع إقلاع الشاشة.
- توقيع ثابت للإصدارات حتى يمكن التحديث فوق النسخ السابقة مستقبلاً.

## الاتصال من الآيفون

1. اجعل الآيفون وشاشة السيارة على نفس شبكة Wi‑Fi.
2. افتح **دربك اتصال** على الشاشة.
3. يظهر عنوان محلي مثل `http://192.168.1.50:8765` مع رمز PIN.
4. افتح العنوان في Safari وأدخل رمز PIN.
5. يمكن إضافة الصفحة إلى الشاشة الرئيسية في iOS كاختصار مستقل.
