# DarbakConnect — دربك اتصال

تطبيق خاص لشاشة السيارة يربط الآيفون بالشاشة عبر الشبكة المحلية Wi‑Fi بدون استضافة خارجية.

## الإصدار الأول 1.0.0

- Android 7.1 / API 25 فما فوق.
- واجهة أفقية محسّنة لدقة 1024×600.
- هوية دربك الليلية: كحلي/أسود + أزرق/سماوي.
- خادم محلي على المنفذ 8765.
- دخول محمي برمز PIN من 4 أرقام.
- تشغيل التطبيقات المثبتة من الآيفون.
- عرض أسماء التطبيقات وأيقوناتها وإصداراتها.
- إرسال MP3 / فيديو / صور / APK من Safari إلى الشاشة.
- حفظ الملفات في مجلدات مناسبة مع فحص APK قبل اعتماده.
- مقارنة إصدار APK المرفوع بالإصدار المثبت.
- فتح مثبت APK على الشاشة بأمان عبر FileProvider.
- حالة RAM والتخزين والبطارية والشبكة ووقت التشغيل.
- سجل آخر العمليات محليًا.
- تشغيل خدمة Darbak Connect مع إقلاع النظام.
- لا Firebase ولا خادم خارجي ولا حسابات.

## الاتصال من الآيفون

1. اجعل الآيفون والشاشة على نفس شبكة Wi‑Fi.
2. افتح تطبيق دربك اتصال على الشاشة.
3. سيظهر عنوان مثل `http://192.168.1.50:8765` ورمز PIN.
4. افتح العنوان في Safari وسجّل الدخول بالرمز.
5. يمكن إضافة الصفحة إلى الشاشة الرئيسية في iOS لتظهر كاختصار مستقل.

## ملاحظة مهمة

التثبيت الصامت للتطبيقات وإيقاف تطبيقات أخرى بالقوة غير مستخدمين لأنهما يحتاجان صلاحيات نظام/Root. Darbak Connect يفتح شاشة التثبيت الرسمية على الجهاز، وهو المسار الآمن والمستقر.
